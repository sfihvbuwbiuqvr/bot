# 🎬🎵 ربات دانلود ویدیو + شناسایی و دانلود موزیک (تلگرام)

ربات تلگرامی پایتونی که:

- 🎬 لینک **یوتیوب / اینستاگرام / تیک‌تاک / ساند‌کلود / اسپاتیفای** را می‌گیرد و دانلود/ارسال می‌کند
- ☁️ **ساند‌کلود**: ترک‌ها خودکار به MP3 تبدیل و به‌صورت فایل صوتی ارسال می‌شوند (معمولاً بدون نیاز به کوکی)
- 🟢 **اسپاتیفای ← MP3**: لینک ترک اسپاتیفای را بدهید، معادلش از یوتیوب پیدا و دانلود می‌شود
- 🎚 **انتخاب کیفیت** قبل از دانلود: 1080p / 720p / 360p / فقط صدا
- 📃 **پلی‌لیست و ست‌ها**: لیست آیتم‌ها با شماره نمایش داده می‌شود؛ انتخاب تکی یا «دانلود همه» (تا ۲۵ آیتم)
- 📨 **ذخیره از کانال‌ها**: پست کانال را فوروارد کنید → کپی بدون هدر فوروارد (+ دکمه «ارسال به‌صورت فایل» تا ۲۰MB)
- 🎵 شناسایی آهنگ با **Shazam** + 🎙 **فرستادن ویس/آهنگ/ویدیو = شناسایی خودکار** + 📝 متن ترانه (lrclib) + ⏱ پیش‌نمایش ۳۰ ثانیه‌ای (ویس) + 🔔 رینگتون
- 🏷 درج خودکار **تگ ID3 و کاور** داخل MP3 (mutagen)
- 🔎 **جستجوی اینلاین**: `@BotName نام آهنگ` در هر چتی
- 🔤 **جستجو با متن ترانه**: چند خط از آهنگ را (فارسی یا انگلیسی) **بدون نام خواننده** بفرست — نام آهنگ با Genius / DuckDuckGo / lrclib تشخیص داده می‌شود و نتایج پین‌شده نمایش داده می‌شود
- 🕘 **تاریخچه دانلود** `/history` با دکمه دریافت مجدد + 🌐 **دوزبانه** fa/en با `/lang`
- 🔒 سیستم **جوین اجباری کامل** با کش عضویت و دکمه‌ی «بررسی مجدد»
- 🛠 **پنل ادمین فول**: آمار، وضعیت سرور، ارسال همگانی، مدیریت کانال‌های اجباری، بن/آنبن، **حالت تعمیر**، **صف دانلود** (روشن/خاموش)، **شزام خودکار**، کانال لاگ خطاها، **سوییچ سرویس یوتیوب/ساند‌کلود/متن‌ترانه/اینلاین/شناسایی‌خودکار**، **تنظیم کول‌داون** و **پاکسازی دستی فایل‌ها**

> ℹ️ نکته درباره‌ی «دکمه شیشه‌ای»: استایل ظاهری دکمه‌های تلگرام را کلاینت هر کاربر تعیین می‌کند و API امکان شخصی‌سازی رنگ/بلور نمی‌دهد؛ برچسب دکمه‌ها مینیمال و تمیز طراحی شده‌اند.

> 🚂 این ربات **آماده‌ی Railway** است: `Dockerfile` + `railway.json` دارد، ffmpeg داخل ایمیج نصب می‌شود و اگر متغیرهای ضروری را ست نکرده باشید، لاگ دیپلوی دقیقاً می‌گوید چه چیزی کم است.

## 📦 نصب

### پیش‌نیازها
1. **Python 3.10+**
2. **ffmpeg** — حتماً نصب باشد (برای تبدیل صدا + Shazam):
   - Ubuntu/Debian: `sudo apt install ffmpeg`
   - CentOS: `sudo yum install ffmpeg`
   - Windows: از gyan.dev دانلود و به PATH اضافه کنید

### مراحل
```bash
# 1) نصب کتابخانه‌ها
pip install -r requirements.txt

# 2) ساخت فایل تنظیمات
cp .env.example .env
nano .env        # BOT_TOKEN و ADMIN_IDS را پر کنید

# 3) اجرا
python bot.py
```

## ⚙️ تنظیمات (.env)

| متغیر | توضیح | پیش‌فرض |
|---|---|---|
| `BOT_TOKEN` | توکن ربات از [@BotFather](https://t.me/BotFather) | — |
| `ADMIN_IDS` | آیدی عددی ادمین‌ها با کاما | — |
| `FORCE_CHANNELS` | کانال‌های جوین اجباری اولیه (@username یا -100...) | خالی |
| `COOKIES_FILE` | مسیر فایل کوکی Netscape | `cookies.txt` |
| `MAX_FILE_MB` | سقف حجم ارسال به تلگرام | `48` |
| `AUDIO_BITRATE` | کیفیت MP3 خروجی | `192` |
| `CLEAN_AFTER_MIN` | عمر فایل‌های موقت قبل از پاک شدن | `45` |
| `SHAZAM_SNIPPET_SEC` | چند ثانیه اولِ صدا برای شناسایی | `95` |
| `DEFAULT_LANG` | زبان پیش‌فرض (`fa` یا `en`) — هر کاربر با `/lang` عوض می‌کند | `fa` |
| `LOG_CHANNEL` | کانال گزارش خطاها (@channel یا -100...) | خالی |
| `MAX_CONCURRENT_DL` | ظرفیت صف دانلود همزمان | `2` |
| `PLIST_MAX_ITEMS` | حداکثر آیتم قابل انتخاب از پلی‌لیست | `25` |

## 🍪 کوکی (مهم برای یوتیوب/اینستاگرام)

فایل کوکی را با فرمت **Netscape** کنار `bot.py` با نام `cookies.txt` بگذارید (یا مسیر دلخواه در `.env`). خودکار تشخیص داده می‌شود.

- **کوکی یوتیوب:** برای محتوای سنی‌دار و رفع خطای «Sign in to confirm...» — افزونه‌ی *Get cookies.txt LOCALLY* روی کروم
- **کوکی اینستاگرام:** برای اکانت‌های خصوصی و کاهش محدودیت 429 — وارد اکانت شوید و کوکی بگیرید
- تیک‌تاک و ساند‌کلود معمولاً بدون کوکی کار می‌کنند

## 🛠 پنل ادمین

با `/admin` باز می‌شود:

- 📊 **آمار**: کل کاربران، جدید/فعال امروز، بن‌شده، تفکیک دانلود به تفکیک پلتفرم، شزام‌های موفق
- 🖥 **وضعیت سرور**: آپتایم، CPU/RAM (با psutil اختیاری)، دیسک، تعداد فایل‌های موقت، وضعیت ffmpeg و cookies
- 📢 **ارسال همگانی**: هر نوع پیام (متن/عکس/ویدیو/فوروارد) → تأیید → ارسال گروهی هوشمند با مدیریت RateLimit
- 🔒 **کانال‌های جوین اجباری**: افزودن (با اعتبارسنجی ادمین‌بودن ربات) و حذف از داخل چت
- 🚫 **بن / ♻️ آنبن** کاربر با آیدی عددی

نصب اختیاری برای نمایش CPU/RAM: `pip install psutil`

## 📡 اجرای دائمی (Linux)

```bash
sudo tee /etc/systemd/system/musicbot.service > /dev/null <<EOF
[Unit]
Description=MusicFinder Telegram Bot
After=network.target

[Service]
WorkingDirectory=/path/to/bot
ExecStart=/usr/bin/python3 /path/to/bot/bot.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl daemon-reload
sudo systemctl enable --now musicbot
journalctl -u musicbot -f     # مشاهده لاگ
```

## 🚂 دیپلوی رایگان روی Railway

فایل‌های آماده: **`Dockerfile`** (پایتون ۳.۱۲ + ffmpeg + ffprobe)، **`railway.json`** (ری‌استارت خودکار، تک‌نمونه) و چکِ هوشمند متغیرها داخل خود بات.

### مرحله ۱ — ریپو را بسازید
این ۴ فایل را در یک ریپوی GitHub بگذارید و push کنید:
`bot.py` · `requirements.txt` · `Dockerfile` · `railway.json` (+ `.env.example` و `README.md` اختیاری)

### مرحله ۲ — پروژه در Railway بسازید
1. وارد [railway.com](https://railway.com) شوید (با GitHub)
2. **New Project → Deploy from GitHub repo** → ریپو را انتخاب کنید
3. ⚠️ اولین دیپلوی **قرار است fail شود** — این طبیعی است! چون هنوز Variables ندارید.

### مرحله ۳ — Variables را قبل از دیپلوی کامل بگذارید
سرویس → تب **Variables** → دکمه **Raw Editor** → این را با مقادیر واقعی paste کنید:

```env
BOT_TOKEN=123456789:AAxxxxxxxxxxxxxxxxxxxx
ADMIN_IDS=123456789
FORCE_CHANNELS=@your_channel
LOG_CHANNEL=
DEFAULT_LANG=fa
```

| متغیر | الزامی؟ | توضیح |
|---|---|---|
| `BOT_TOKEN` | ✅ | توکن از [@BotFather](https://t.me/BotFather) |
| `ADMIN_IDS` | ✅ | آیدی عددی شما از [@userinfobot](https://t.me/userinfobot) |
| `FORCE_CHANNELS` | ➖ | جوین اجباری؛ خالی = خاموش (بعداً از پنل ادمین هم می‌شود) |
| `LOG_CHANNEL` | ➖ | کانال گزارش خطاهای دانلود |
| `COOKIES_B64` | ➖ | اگر یوتیوب خطای Sign in داد؛ محتوای base64 فایل cookies.txt |

ذخیره که کنید، **Railway خودکار دوباره دیپلوی می‌کند**. اگر باز هم چیزی کم باشد، لاگِ دیپلوی یک کادر فارسی نشان می‌دهد که دقیقاً کدام متغیر را باید اضافه کنید (ربات تا پر نشدن متغیرهای ضروری بالا نمی‌آید).

### مرحله ۴ — دیتابیس ماندگار روی سایت
دیتابیس SQLite خودکار ساخته می‌شود؛ فقط برای اینکه بعد از هر ری‌دیپلوی از دست نرود:

1. سرویس بات → تب **Settings/Storage** → **+ New Volume**
2. مسیر مونت: `/data`
3. تمام! (`Dockerfile` پیش‌فرض‌های `DB_PATH=/data/bot.db` و `DOWNLOAD_DIR=/data/downloads` را ست کرده)

### نکته‌ها
- 🍪 کوکی لازم شد؟ متغیر `COOKIES_B64` بسازید:
  - لینوکس/Mac: `base64 -w0 cookies.txt` → خروجی را در متغیر بگذارید
  - ویندوز PowerShell: `[Convert]::ToBase64String([IO.File]::ReadAllBytes("cookies.txt")) | Set-Clipboard`
- 🔌 Healthcheck (اختیاری): Settings → Networking → Generate Domain؛ ربات وقتی `PORT` ست شده باشد روی `/` یک JSON وضعیت برمی‌گرداند — می‌توانید UptimeRobot هم به آن وصل کنید
- 💰 مصرف پلن Trial/Hobby خیلی پایین است (polling سبک + بدون ترافیک وب)
- ♻️ هر push جدید به GitHub = دیپلوی خودکار

## ❓ سوالات رایج

**چرا ویدیویی ارسال نمی‌شود؟**
